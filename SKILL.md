## Panel-specific overlay

Build imagery from characters, dots and low-resolution raster units, not continuous blocks. Preserve ordered density hierarchy and an integrated experimental bitmap title with sparse supporting copy. Use black/white/grey with 1–3 source-derived accents, a small subject and vast whitespace. Avoid uncontrolled glitch, full-scene tracing and ordinary pasted-on titles. If text-free delivery conflicts with character-built imagery, explain the conflict and resolve it before spending an image call; never silently replace the defining visual language.

These overlay rules add to `references/soldier-runtime.md`. They never replace the source brief or the family runtime contract.

Write every selected final PNG directly inside one fresh task directory under `~/Desktop/xxd/xxd-panel-159/` (or the explicit `--out` root). Use collision-safe filenames; do not create source, mode, or size subdirectories and do not generate an automatic contact sheet.
